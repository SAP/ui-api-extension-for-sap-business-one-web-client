## Summary

The SAP Business One Web Client UI API was introduced in FP 2405. It lets customers and partners build UI extensions on top of Web Client by adding or overriding controls in existing views. The framework wraps SAP UI5 — controls are customised UI5 descendants exposed via the `b1.sdk` namespace — but direct UI5 access is not permitted. Only a subset of controls and views are supported at any given release; the set grows with each feature pack.

Extension code requires a minimum of **ECMAScript 2017 (ES8)**. ES8 is guaranteed to work; ES2018+ syntax may also work depending on the UI5 version bundled with Web Client and the browser — support grows over time. ES8 is the safe baseline to target.

The overlay mechanism is the primary way extensions modify views. An extension ships `*.layout.json` files that declare where and how to insert or update controls using GUID-based positional keys (`before`, `after`, `on`, `move`). A paired JavaScript controller file handles event logic. As of FP2511, `on` can also patch event handlers into grid cell controls via a `template` block inside a Column definition.

## Key facts

- UI API available from **FP 2405**.
- Controls namespace: `b1.sdk.*` (e.g. `b1.sdk.Button`, `b1.sdk.ButtonType.Accept`).
- Extension namespace = `provider name` + `app name` + `module name`; auto-generated by the UIAPI creation wizard and stored in `manifest.json`.
- Overlay file naming convention: `*.layout.json`.
- Positional operators: `before` (insert before GUID), `after` (insert after GUID), `on` (override/update existing GUID), `move` (relocate UDF to a custom section).
- `move` is only valid within sections/tabs — moving to the document header is unsupported and not recommended.
- **FP2511**: `on` operator supports a `template` sub-block to patch before/after event handlers onto grid cell controls; reference the Column GUID (without `COLUMN_` prefix) and the cell control's GUID.
- Duplicate GUIDs in a view cause a runtime error.
- Invalid or wrongly-positioned properties in overlay JSON will likely cause a runtime error on load.
- The VS Code plugin provides static checking of overlay JSON against a predefined schema.
