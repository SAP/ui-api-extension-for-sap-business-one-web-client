## Values

| Value | Description |
|---|---|
| `Row` | Rows can be selected by clicking anywhere on the row |
| `RowOnly` | Rows can only be selected on the row body (selector is hidden) |
| `RowSelector` | Rows can only be selected on the row selector (default) |

## Where used

- [[b1sdk-grid]] — `selectionBehavior` property (default: `RowSelector`)

## Notes

**Namespace**: `b1.sdk.Grid.SelectionBehavior` — scoped to Grid, not top-level `b1.sdk`. This is one of only three sub-namespaced enums in the SDK.
