## Values

| Value | Description |
|---|---|
| `Auto` | Empty indicator rendered based on context |
| `Off` | Empty indicator never rendered |
| `On` | Empty indicator always rendered when content is empty |

## Where used

- [[b1sdk-objectstatus]] — `emptyIndicatorMode` property
- [[b1sdk-objectnumber]] — `emptyIndicatorMode` property

## Notes

When `On`, an empty control shows a placeholder indicator instead of blank space, improving readability in forms and tables.
